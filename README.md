# منير HQ

نظام تشغيل الحياة. الاهداف والمشاريع والمهام والعادات والكالندر والفلوس والمراجعة الاسبوعية، كلها في منتج واحد يشتغل عنك.

بني بـ Next.js 15 و Supabase و Tailwind v4، ويطلع من Vercel.

---

## وش فيه

**الشجرة اللانهائية** — هدف ← مشروع ← مهمة ← مهمة فرعية ← الى ما لا نهاية. نسبة الانجاز تتحسب من الاوراق وترتفع لفوق تلقائي، فما تحتاج تحدث اي رقم بنفسك.

**الاضافة السريعة** — تكتب بالعامية والنظام يفهم: "اجتماع سند بكرة !1 ساعة #نمو @شغل" يصير مهمة بتاريخ بكرة واولوية عالية وتقدير ساعة ووسم نمو في جانب الشغل. تفتحها من زر n في اي مكان.

**لوحة الاوامر** — ⌘K او / تفتح بحث فوري في كل مهامك، وتقدر تخلص المهمة من داخلها بـ ⌘+Enter.

**السحب والافلات** — ترتب المهام وتعشش الواحدة تحت الثانية بالسحب، وتنقل مهمة من يوم ليوم في شاشة الاسبوع.

**قوقل كالندر** — ربط بضغطة، ومزامنة بالاتجاهين كل ربع ساعة. فيه زر "رتب اسبوعي تلقائيا" يوزع مهامك على الفراغات الفاضية في كالندرك حسب الاولوية والوقت المقدر.

**العادات** — تتبع يومي، سلسلة ايام متتالية، هدف اسبوعي، وخريطة حرارية 30 يوم تقدر ترجع تعبي فيها اي يوم فاتك.

**المتابعة اليومية** — وزن، دهون، نوم، خطوات، طاقة، رياضة، مع رسوم بيانية.

**المالي** — دخل ومصروف، متوقع مقابل فعلي، تصنيفات، وصافي شهري تراكمي.

**المراجعة الاسبوعية** — تفتح كل سبت بالارقام جاهزة، وفيها خانة "القيد الواحد لكل جانب" على منهجية السقف.

**الانجازات** — خط زمني لكل شي خلصته، ينضاف تلقائي لما تخلص هدف.

**الاوتوميشن** — ست وظائف تشتغل بالخلفية: مزامنة الكالندر، ملخص صباحي بالايميل، ترحيل المتاخر، تجهيز المراجعة، لقطة تقدم اسبوعية، وتنبيه لما جانب يهمل 10 ايام.

**يشتغل على الجوال** — PWA تقدر تثبتها على شاشتك الرئيسية، وكل شي يتزامن لحظيا بين اجهزتك.

## اللوقو

لوقو منير مركب جاهز في المشروع، ما يحتاج اي شي منك:

- `public/logo.png` — الشعار الاصلي، يظهر في القائمة الجانبية وصفحة الدخول والاعدادات.
- `public/icons/icon-192.png` و `icon-512.png` و `icon-maskable-512.png` — ايقونات التطبيق لما تثبته على الجوال.
- `public/apple-touch-icon.png` — ايقونة الايفون.
- `src/app/favicon.ico` — ايقونة التبويب في المتصفح.
- `public/og.png` — صورة المشاركة لما ترسل الرابط في واتساب او تويتر.

لو حبيت تبدله لاحق: بدل `public/logo.png` بنفس الاسم، او افتح `/settings` وحط رابط شعار ثاني في خانة "رابط اللوقو" ويطبق فورا بدون رفع جديد.

اسم التطبيق ياخذه من `NEXT_PUBLIC_APP_NAME` (الافتراضي: منير HQ).

## التشغيل بخمس خطوات

### 1. سوبابيس

انشئ مشروع جديد على [supabase.com](https://supabase.com)، بعدين:

- افتح **SQL Editor** والصق كل محتوى `supabase/schema.sql` واضغط Run. هذا ينشئ الجداول والصلاحيات (RLS) والتريقرات ودالة حساب التقدم.
- افتح **Database ← Replication** وفعل الـ Realtime على جدول `nodes` عشان التزامن اللحظي بين اجهزتك.
- من **Project Settings ← API** خذ: `Project URL` و `anon key` و `service_role key`.

### 2. قوقل (اختياري بس يستاهل)

من [Google Cloud Console](https://console.cloud.google.com):

- فعل **Google Calendar API**.
- انشئ **OAuth 2.0 Client ID** نوع Web application.
- في Authorized redirect URIs حط: `https://<مشروعك>.supabase.co/auth/v1/callback`
- خذ الـ Client ID والـ Client Secret.

بعدين في سوبابيس: **Authentication ← Providers ← Google**، فعله والصق الـ Client ID والـ Secret، وفي خانة Scopes حط:

```
https://www.googleapis.com/auth/calendar
```

### 3. المتغيرات

انسخ `.env.example` الى `.env.local` واملاه:

```
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
SUPABASE_SERVICE_ROLE_KEY=...
NEXT_PUBLIC_SITE_URL=http://localhost:3000
NEXT_PUBLIC_APP_NAME=منير HQ
GOOGLE_CLIENT_ID=...
GOOGLE_CLIENT_SECRET=...
CRON_SECRET=اي نص طويل عشوائي
RESEND_API_KEY=...
DIGEST_TO_EMAIL=...
DIGEST_FROM_EMAIL=...
```

الـ `service_role` والـ `CRON_SECRET` ما يتحطون ابدا في الكود ولا يترفعون على قيت هب. بس في متغيرات البيئة.

### 4. محليا

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`، سجل دخول، وبتطلع لك شاشة البداية: اما تبدأ بخطتك الجاهزة (6 جوانب و 99 مهمة نهائية) او من صفر.

### 5. قيت هب وفيرسال

```bash
git init
git add -A
git commit -m "منير HQ"
git branch -M main
git remote add origin https://github.com/<حسابك>/<المستودع>.git
git push -u origin main
```

بعدها على [vercel.com](https://vercel.com): New Project ← استورد المستودع ← الصق نفس المتغيرات في Environment Variables ← Deploy.

بعد اول نشر:

- حدث `NEXT_PUBLIC_SITE_URL` لرابط فيرسال.
- في سوبابيس **Authentication ← URL Configuration** حط رابط فيرسال في Site URL، وضيف `https://<رابطك>/auth/callback` في Redirect URLs.

الكرون في `vercel.json` يتفعل تلقائي عند النشر.

> **مهم عن خطة Vercel المجانية (Hobby):** الخطة المجانية ما تسمح بكرون يشتغل اكثر من مرة في اليوم، واي جدولة اسرع من كذا **تفشل عملية النشر نفسها**. عشان كذا `vercel.json` المرفق مضبوط على جدولة يومية تشتغل على المجاني بدون اي مشكلة. ومزامنة الكالندر ما تتعطل: التطبيق يزامن تلقائي كل ما تفتحه (بحد اقصى مرة كل 10 دقائق)، فكالندرك محدث دايم.
>
> لو رقيت لـ **Pro**: غير اسم `vercel.pro.json` الى `vercel.json` وارفع، بتصير المزامنة كل ربع ساعة بالخلفية حتى وانت ما فتحت التطبيق.
>
> بديل مجاني للمزامنة كل ربع ساعة: سجل في اي خدمة كرون خارجية مجانية وخلها تناديك على:
> `https://<رابطك>/api/cron/calendar_sync?key=<CRON_SECRET>` كل 15 دقيقة.

## الاوتوميشن

| الوظيفة | متى | وش تسوي |
|---|---|---|
| `calendar_sync` | كل 15 دقيقة | ترفع المهام المجدولة لقوقل وتسحب اي تغيير سويته من كالندرك |
| `daily_digest` | 7 صباحا | ايميل فيه متاخراتك ومهام يومك وعاداتك وتقدم جوانبك |
| `rollover` | 12:30 ليلا | تنقل مهام امس اللي ما خلصت لليوم |
| `weekly_review` | السبت 6 صباحا | تجهز مراجعة الاسبوع الماضي بالارقام |
| `snapshot` | السبت 6:10 | تحفظ نسبة كل جانب عشان يطلع منحنى تقدمك |
| `neglect_nudge` | 8 صباحا | تنبهك لو جانب مر عليه 10 ايام بدون حركة |

تشغلها او تطفيها من `/settings`. وتقدر تشغل اي وحدة يدويا:

```
curl -X POST "https://<رابطك>/api/cron/daily_digest?key=<CRON_SECRET>"
```

الايميل يحتاج مفتاح [Resend](https://resend.com) وايميل مرسل موثق. بدونه باقي الاوتوميشن يشتغل عادي.

## نسختك الاحتياطية

`/api/export` ينزل لك JSON فيه كل شي: الجوانب، الشجرة كاملة، العادات، القياسات، الفلوس، الانجازات، والمراجعات. ومن `/settings` فيه زر مباشر.

## البنية

```
src/
  app/
    (app)/            الشاشات: الرئيسية، اليوم، الاسبوع، الجوانب، العادات، المتابعة، المالي، المراجعة، الانجازات، الاعدادات
    api/
      calendar/       schedule · sync · autoplan
      cron/[job]      محرك الاوتوميشن
      setup           تعبئة خطتك اول مرة
      export          النسخة الاحتياطية
    auth/callback     يستقبل دخول قوقل ويحفظ توكن الكالندر
    login
  components/         Store (المخزن اللحظي) · Shell · TaskTree · TaskPanel · QuickAdd · CommandPalette · Board · Donut · LifeWheel ...
  lib/                tree (حساب التقدم) · nlp (فهم العامية) · google · scheduler · dates · supabase
  data/seed.json      خطتك الجاهزة
supabase/schema.sql   قاعدة البيانات كاملة
vercel.json           جدول الكرون
```

نسبة الانجاز محسوبة بنفس المعادلة في مكانين: `src/lib/tree.ts` للواجهة، ودالة `area_progress` في قاعدة البيانات للاوتوميشن. لو غيرت وحدة غير الثانية معها.

## ملاحظات

- كل البيانات محمية بـ RLS على مستوى قاعدة البيانات. حتى لو انكشف الـ anon key، احد ما يقدر يقرأ صفك.
- الواجهة عربية RTL بالكامل، والارقام لاتينية بعزل ثنائي الاتجاه عشان ما تنقلب.
